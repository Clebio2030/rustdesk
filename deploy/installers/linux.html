Instalação rápida via Terminal
Ubuntu / Debian / Pop!_OS:
$ wget -O maxdesk.deb https://maxdesk.csdigitalz.com.br/deb && sudo dpkg -i maxdesk.deb
Arch Linux / Manjaro / Fedora (.tar.gz):
$ wget -O maxdesk.tar.gz https://maxdesk.csdigitalz.com.br/download/maxdesk.tar.gz && tar -xzf maxdesk.tar.gz && ./maxdesk

Dica para Arch Linux, Manjaro & EndeavourOS

Utilize a versão .tar.gz — ela já inclui o runtime Flutter. Caso falte alguma biblioteca de sistema para aceleração gráfica ou áudio, instale via Pacman:
sudo pacman -S gtk3 libpulse gst-plugins-base
