Qual versão devo baixar?

Se o seu computador é recente e roda Windows 10 ou 11, baixe o 64-bit. Caso você tente abrir o 64-bit e o Windows exiba o erro "Este aplicativo não pode ser executado no seu PC", significa que o seu sistema é de 32 bits — nesse caso, baixe a versão 32-bit.
